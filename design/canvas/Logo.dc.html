FIXA logo

Stroke thickens as size drops. At 16 px the dot is dropped so the roof stays crisp. Used for the PWA install icon and the browser tab.

Construction

One stroke weight (14 on an 80-unit cap height), round caps and joins. The F’s middle bar sits on the optical centre. The A has no crossbar; the dot takes its place.

Use it well

  • Clear space on every side: the height of the A’s dot × 3.
  • Minimum width: 64 px for the wordmark, 16 px for the mark.
  • The signal dot is the only orange in the brand. It means “noticed”, never “danger”.
  • Don’t stretch, outline, add shadows or set the wordmark in a font.
  • Write the name as FIXA in the logo and Fixa in running text.
